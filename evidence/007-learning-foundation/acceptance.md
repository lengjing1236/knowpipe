# Feature 007 第一阶段验收

日期：2026-09-23。分支：`007-learning-foundation`。

[已验证] 按 SpecKit specify → plan → tasks → implement 执行；需求质量检查 10/10 通过，15 项阶段任务完成。无扩展 hooks。新规约独立于 Feature 001–006。

## 已实现的用户路径

- 从现有首页进入 `/learning` 中文学习工作台，保存、修改和刷新当前学习目标。
- 分页浏览公开资料，按标题或实际来源筛选；只有显式操作才标记已读，可查看并撤销个人历史。
- 已读带所读正文版本；打开旧版后内容更新，标记返回 409 并在阅读窗口内提示重新打开，不误记新版已读。
- 完整中文正文默认展示中文；英文没有合格译文时说明未就绪，允许主动查看原文。旧摘要与缺答案的问题正文不冒充全文。
- 完整正文发布、原文版本、阶段状态、译文缓存和过期结果条件写入；提供方未配置或结果不完整时不伪造成功。
