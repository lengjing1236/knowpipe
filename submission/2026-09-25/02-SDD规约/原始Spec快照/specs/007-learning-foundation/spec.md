# Feature Specification: 学习目标、阅读记录与全文状态基础

**Feature Branch**: `007-learning-foundation`
**Created**: 2026-09-23
**Status**: [已验证] 第一阶段已实现并通过验收；总体推荐与模型链路继续按根规划推进
**Input**: 用户要求“开始实现的话，使用 SpecKit skill”；依据根目录 plan.md 已确认共识交付第一阶段，不将其等同于全部推荐系统完成。

## User Scenarios & Testing

### User Story 1 - 保存自己的学习目标 (Priority: P1)

[已验证：用户需求] 学生可以记录、修改自己的当前学习目标，刷新后仍保留。主题不限定为 Pandas。

**Why this priority**: 后续目标相关推荐需要明确输入。
**Independent Test**: 用户甲保存“理解 Redis 持久化”并刷新；用户乙看不到甲的目标。
**Acceptance Scenarios**:

1. **Given** 新账户，**When** 打开工作台，**Then** 目标为空，能输入中文目标。
2. **Given** 已登录账户，**When** 保存或修改目标，**Then** 刷新和重新登录后保留。
3. **Given** 不同账户，**When** 读取或修改目标，**Then** 只能操作自身目标；不声称保存后已完成推荐计算。

### User Story 2 - 主动建立并撤销阅读记录 (Priority: P1)

[已验证：用户需求] 仅主动标记“已读”的资料进入历史，打开本身不计入；已读不表示掌握。

**Why this priority**: 后续对照需要真实、可管理的个人输入。
**Independent Test**: 浏览不改变历史；标记后出现在个人已读列表，重复标记只有一条，撤销后消失。
**Acceptance Scenarios**:

1. **Given** 未读资料，**When** 仅打开详情，**Then** 阅读记录不变。
2. **Given** 存在的公开资料，**When** 标记已读，**Then** 保存来源、标识、内容版本和时间，重复请求不重复记录。
3. **Given** 已读资料，**When** 撤销已读，**Then** 仅从自身历史移除，重复撤销成功。
4. **Given** 已读资料更新或删除，**When** 查看历史，**Then** 显示版本变化或不可用，仍可撤销，不冒充读过新版。
5. **Given** 标记已读后保存旧页面主题偏好，**When** 查看已知关键词，**Then** 不因已读自动增加掌握判断。
6. **Given** 页面已打开旧版，**When** 后台更新正文后用户标记已读，**Then** 提示重新打开资料，不保存用户未看到的新版指纹。

### User Story 3 - 确认资料是否能完整阅读 (Priority: P2)

[已验证：用户需求] 需要全文及中文阅读，不能把摘要或处理中的内容标成已就绪。

**Why this priority**: 后续推荐需要可信的正文与处理状态。
**Independent Test**: 完整中文、完整英文、仅摘要、失败及译文过期样例分别显示准确状态。
**Acceptance Scenarios**:

1. **Given** 原有论文摘要或仅问题正文，**When** 浏览，**Then** 标为摘要或缺解答，不称为全文。
2. **Given** 完整中文正文，**When** 阅读，**Then** 默认中文，保留段落及代码换行。
3. **Given** 英文全文与同版本完整中文译文，**When** 阅读，**Then** 默认中文，可切换原文；部分或过期译文不显示为全文。
4. **Given** 英文资料暂无译文，**When** 阅读，**Then** 明确尚未就绪，可主动查看原文。
5. **Given** 正文变化，**When** 读取状态，**Then** 旧译文与分析不能继续标为当前版本已就绪。

### Edge Cases

[方案] 空白／超长／非文本目标、未登录、伪造账户、非法分页、缺失资料、重复和并发标记、含斜线的旧论文 ID、危险 HTML、空正文、旧数据无完整性字段、部分与过期译文、未配置服务。原文以文本显示，不执行资料中的标签。

## Requirements

### Functional Requirements

- **FR-001**: 每个账户保存一个当前目标，长度 1–1000 字符并去除首尾空白，支持中文及其他文字。
- **FR-002**: 目标与历史仅由当前账户操作，拒绝伪造他人身份、非法请求与跨站写入。
- **FR-003**: 提供分页公开资料列表、来源筛选、标题检索及个人已读列表。
- **FR-004**: 提供“标记已读／撤销已读”；浏览、目标变更及通知已读不自动标记资料已读。
- **FR-005**: 历史按来源与标识去重并记录时间与内容版本；操作幂等，不丢失同时发生的不同资料标记。
- **FR-006**: 目标或历史变化增加输入修订号；重复提交相同操作不增加，供后续推荐判断过期。
- **FR-007**: 已读不自动转为掌握；旧评分可读取引用，但不得称为新推荐算法。
- **FR-008**: 区分全文、摘要、仅问题、未验证、缺失与提取失败；缺省不推定完整。
- **FR-009**: 保存原文及版本，区分提取、转写、翻译、分析状态；没有产物不能显示完成。
- **FR-010**: 仅同版本、非空、完整译文用于中文全文；原文变化使旧译文与分析失效。
- **FR-011**: 默认显示可用中文；没有中文时说明状态，允许主动查看原文，不伪造翻译。
- **FR-012**: 新工作台为中文，可从现有首页进入，错误、空列表及处理状态可理解。

### Key Entities

- **学习目标**：当前账户的文本目标及修改时间。
- **阅读记录**：账户、来源、标识、时间及已读版本；资料更新不代表用户读过新版。
- **资料内容**：来源、原文、语言、完整性、版本及来源链接。
- **处理状态**：提取、转写、翻译、分析阶段及其版本，区分失败与服务未配置。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 两账户隔离场景全部通过；刷新及重新登录后目标与历史保留。
- **SC-002**: 浏览不写历史，重复标记、撤销、删除及更新场景全部满足 US2。
- **SC-003**: 完整中文、英文有译文、英文无译文、摘要、仅问题、失败和过期译文七类场景全部准确；零次将摘要或过期译文作为全文。
- **SC-004**: 从首页进入工作台，保存目标、找到资料、标记及撤销；桌面与手机尺寸无横向溢出。

## Assumptions

[方案] 复用账户和公开资料库；本阶段为单一当前目标和账户范围历史，撤销可纠正误标。旧历史缺时间或版本时返回未知，不补造记录。历史只保存所读版本指纹，本阶段不保存旧正文快照，因此不能据新版正文精确对照旧阅读内容。

[方案] 本阶段实现全文存取、状态及可替换的转写／翻译接口；未配置服务显示不可用，不调用付费服务、不把替身当真实模型。全文补采、规模语料重建、Spark 新推荐算法、RSS 音频处理及真实翻译验收保留为后续阶段，并未取消。

[方案] 验证包含隔离、幂等并发及版本失效的自动测试和中文页面浏览器检查。本阶段不宣称达到有效全文规模或推荐效果指标。
