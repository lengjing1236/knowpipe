# 研究与决策

[已验证] 已由两个只读研究任务核查现有历史/worker和算法边界。

- **Decision**: 原文段落的平滑 IDF + 对数词频、归一化向量构成基线；倒排词项 join 算余弦。
  **Rationale**: 目标与正文共享特征，不只依赖标题；无需收集全向量。**Alternatives**: 不复用旧代表关键词小候选池；暂不引入未经资源确认的语义模型。
- **Decision**: 中文 jieba + 英文技术词 + 版本化有限同义术语归一。**Rationale**: 原文先分析符合 B3；不能把全文翻译当全库前置。**Alternatives**: 只分析已有中文译文会违背用户已确认的翻译时机。能力仍限词汇匹配。
- **Decision**: 前 100 文档各取 3 个相关段落，对可用历史做最大余弦重合，R=max relevance，U=加权平均(1-overlap)，S=R*(0.6+0.4U)。无相关历史退回 R；MMR 用 0.85*S-0.15*与已选最大相似度，近重复阈值 .95。
  **Rationale**: 不相关的陌生词不能胜出；保留候选和历史原文证据。**Alternatives**: 新词比例或来源数量不等于补充价值。MMR 原理参考 Carbonell & Goldstein 1998，标准 TF-IDF 不当作新发明。
- **Decision**: Mongo 原子领取和 attempt_token/到期租约控制完成，结果绑定 profile.learning_revision 与语料 ID。读取再核验候选和历史指纹。**Rationale**: 旧 worker 和新目标不能被较早任务覆盖。
- **Decision**: 独立 worker 持久 Spark 会话与单活租约；周期扫描已保存目标补建缺失任务。**Rationale**: 不依赖 HTTP 写入另一个集合成功，避免丢失处理意图。
- **Decision**: 仅原文版本一致的历史参与比较。**Rationale**: 007 没有旧正文快照；不得用新版替代。原文证据不依赖可变化的译文，中文模板不冒充翻译。
- **Decision**: 真实全文导入通过声明完整性的 JSONL 契约，并记录来源和许可；样例采集正文保留独立来源。**Rationale**: 新算法不能默认把旧摘要变成全文。

[已验证] hooks 配置不存在。真实翻译服务未确定，入选英文资料使用已有提供方接口准备；未配置时状态 unavailable，不重复付费或伪造结果。

[已验证／验收修正] 首次真实中文样例中，25% 目标词覆盖使“数据库事务提交与回滚”误召回仅命中“提交”的异步任务资料。改为至少覆盖 50% 目标词，并加入同词不同义的回归例。此为根据开发样例修正召回门槛；这批样例不能再作为独立效果评测或用于证明泛化提升。
