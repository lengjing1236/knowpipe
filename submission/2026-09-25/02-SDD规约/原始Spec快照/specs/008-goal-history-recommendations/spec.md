# Feature Specification: 目标与阅读历史驱动的推荐

**Feature Branch**: `008-goal-history-recommendations`
**Created**: 2026-09-25
**Status**: [已验证] 第二阶段已实现并验收；总体功能仍分阶段推进
**Input**: 用户要求继续实现并沿用 SpecKit，以根规划和 Feature 007 为基础。

## User Scenarios & Testing

### User Story 1 - 围绕保存的目标获得资料 (Priority: P1)

[已验证：用户需求] 根据当前技术学习目标，从公共资料分析结果获得相关资料，无须先建立历史。
**Why this priority**: 让目标实际影响候选和排序。
**Independent Test**: 同一语料保存两个不同目标，获得对应正文依据；无匹配明确返回空。
**Acceptance Scenarios**:

1. **Given** 目标和合格全文，**When** 请求推荐，**Then** 后台处理后返回资料及真实正文依据，期间显示处理中。
2. **Given** 无目标、无合格全文或无匹配，**When** 请求推荐，**Then** 返回不同状态，不拿热门度或摘要填充。
3. **Given** 英文全文入选，**When** 发布推荐，**Then** 自动准备中文；没有服务则显示不可用，不伪造翻译。

### User Story 2 - 减少与已读资料重复 (Priority: P1)

[已验证：用户需求] 参考主动标记已读的历史，指出可能补充的资料，不把词汇差异称为新知识。
**Why this priority**: 个性化要产生可核验的行为变化。
**Independent Test**: 固定目标与语料，加入已读资料后重复内容降序，同主题不同内容保留并附双方片段。
**Acceptance Scenarios**:

1. **Given** 当前版本的已读材料，**When** 推荐，**Then** 对目标相关段落计算重合，降低高重合资料与列表内重复的优先级。
2. **Given** 历史已更新、删除或无版本，**When** 对照，**Then** 不用新版冒充读过的旧版，并报告不可比较数量。
3. **Given** 无有效相关历史，**When** 推荐，**Then** 仅说明目标相关，不声称发现未知知识。
4. **Given** 镜像或包含很多新词的无关资料，**When** 排序，**Then** 不为凑来源引入重复或无关内容。

### User Story 3 - 可信的异步结果与阅读 (Priority: P2)

[方案] 能刷新推荐状态并打开中文阅读，后台中断或输入变化不把过期结果当成新结果。
**Why this priority**: 推荐计算需要与网页请求分离。
**Independent Test**: 重复请求不重复建立相同任务；计算中修改目标，旧任务不能发布为当前结果。
**Acceptance Scenarios**:

1. **Given** 正在计算，**When** 目标或历史修改，**Then** 旧推荐失效并为新输入准备任务。
2. **Given** 候选或历史正文变化，**When** 查看结果，**Then** 不展示过期依据为当前建议。
3. **Given** worker 中断或租约过期，**When** 恢复处理，**Then** 仅有效令牌能完成任务，重试次数有限。
4. **Given** 已生成推荐，**When** 查看卡片，**Then** 理解推荐原因、看到中文状态、打开资料；其他账户不可访问。

### Edge Cases

[方案] 空目标、停用词、只在标题匹配、开场白误匹配、无交集、摘要、缺答案正文、过期历史、全部重复、超限、并发抢占、账户切换、服务未配置和部分译文。

## Requirements

### Functional Requirements

- **FR-001**: 目标和历史来自当前账户的一致快照，绑定输入修订号。
- **FR-002**: 候选来自显式验证的全文并保留原文版本，摘要不冒充全文。
- **FR-003**: 原文先分析、入选后自动准备中文，不要求全库先翻译。
- **FR-004**: 根据目标与正文段落的相关程度召回，返回偏移和依据，零匹配返回空。
- **FR-005**: 仅用版本匹配历史计算重合，不推导掌握，不可用历史单独统计。
- **FR-006**: 结合目标相关性、段落重合重排并控制列表近重复，不用新词数量声称增量。
- **FR-007**: 保留纯目标基线与历史/去重消融结果，在相同候选上可比较。
- **FR-008**: 任务持久化、去重、租约恢复、有限重试；网页不执行耗时计算。
- **FR-009**: 绑定语料、算法、输入及资料版本，过期任务和依据不得作为当前结果。
- **FR-010**: 任务与结果按会话隔离，写入有跨站保护。
- **FR-011**: 中文模板解释配真实候选/历史原文片段，说明词汇重合能力边界。
- **FR-012**: 页面显示准备中、失败、空结果、历史不足、过期和中文准备状态，可打开阅读。
- **FR-013**: 候选与结果有上限，语料或历史超限明确失败，不静默截断后声称完整。
- **FR-014**: 用真实中文技术全文验证，记录来源与数量；小样例不冒充万条或效果证据。

### Key Entities

- 公共分析快照：全文集合、身份、版本、规模、特征版本。
- 推荐任务：账户、目标、历史、修订号、快照、令牌、重试与状态。
- 推荐结果：资料、排序、目标依据、历史重合依据、算法版本。
- 中文准备记录：入选原文版本及中文状态，复用同版本成功译文。

## Success Criteria

- **SC-001**: 目标切换、相关/无关/无历史、过期历史测试符合规则。
- **SC-002**: 开场白、仅标题、无关新词及镜像测试不产生伪造补充结论。
- **SC-003**: 所有解释片段等于对应版本的原文切片，隔离和过期发布检查通过。
- **SC-004**: 桌面和手机完成保存目标、请求、等待、阅读依据及资料，无横向溢出。
- **SC-005**: 保存真实运行与基线/消融记录；没有独立标签只报告机制验证。

## Assumptions

[方案] 词汇基线使用中文分词、英文技术词和有限显式术语归一，不声称通用跨语言语义理解。允许短列表或空结果。英文原文依据明确标识，中文模板不能冒充译文。

[方案] 已保存目标可自动准备推荐，用户可刷新；本阶段尚非 RSS 推送。模型未配置时明确不可用，不做付费调用。历史无旧正文快照，仅比较版本一致的原文。

[方案] 万条有效全文、独立效果评价、完整 RSS 转写和跨主机集群仍为后续整体要求。
