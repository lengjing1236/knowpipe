## 状态、停止与故障定位

```bash
python3 scripts/defense_demo.py status
python3 scripts/defense_demo.py stop
```

停止服务保留 `state/defense/mongo/` 数据。不要删除该目录。配置、密码、日志和数据库位于被 Git 忽略的 `state/defense/`。

- 网页未打开：看 `state/defense/web-local.log`。
- MongoDB 启动失败：看 `state/defense/mongo.log`；可用 `MONGOD_BIN=/你的路径/mongod` 指定已安装程序。
- 节目未完成：看 `state/defense/worker.log`。
- 临时公网问题：看 `state/defense/tunnel.log`，回到本机入口演示。
