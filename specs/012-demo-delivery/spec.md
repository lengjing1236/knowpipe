# Feature Specification: 中文演示版与课程六项交付

**Feature Branch**: `012-demo-delivery`（规格标识；Git分支见提交记录）
**Created**: 2026-09-25
**Status**: Ready for implementation
**Input**: 用户要求立即得到能视频演示的版本，并提交截图所列六项交付物；此前明确翻译仅用免费远程模型。

## User Scenarios & Testing

### User Story 1 - 完成真实学习演示 (Priority: P1)
学生打开本机网页，保存中文学习目标，查看真实计算的推荐，阅读全文并标记已读，再看到新的处理结果与自己的阅读记录。
**Why this priority**: 截止前需要可录制、可复现的实际系统。
**Independent Test**: 从登录页面操作一轮，核对页面与持久记录一致。
**Acceptance Scenarios**:
1. 已准备来源可追溯的中文全文，保存目标后得到真实处理状态和推荐结果。
2. 打开资料不增加已读数；主动标记后记录增加，重新推荐处理该历史。
3. 不支持的比较显示依据不足，不把已读等同掌握，不声称补充质量已验证。

### User Story 2 - 交付可检查的课程材料 (Priority: P1)
提交人得到源码地址、SDD文档与提示词、项目报告、备份演示视频、最终分工表和汇报PPT。
**Why this priority**: 六项是用户给定的提交要求。
**Independent Test**: 清单逐项打开文件，视频不超过5分钟，报告与演示事实一致。
**Acceptance Scenarios**:
1. 视频是实际页面操作，等待压缩或预处理明确标注，非伪造交互。
2. 规约包含需求与设计，提示词注明真实导出范围，不编造遗失历史。
3. 分工使用已有成员资料，未核实的当前比例或初版差异明确待本人核对。

### User Story 3 - 免费远程翻译 (Priority: P2)
有远程凭据时可准备入选英文全文的中文版本；无凭据时中文原文仍可正常阅读，英文资料显示尚未准备。
**Why this priority**: 保持免费远程要求，并让中文演示不依赖外部账户。
**Independent Test**: 验证成功、缺凭据、限流、输出截断及代码保留。
**Acceptance Scenarios**:
1. 仅调用明确配置的免费远程翻译服务，失败不自动转收费或本地模型。
2. 不完整译文不显示为成功；无真实调用不得宣称远程质量通过。

### Edge Cases
- 服务未启动、端口占用、缺少语料：给出启动与修复信息，不覆盖用户数据库。
- 限流或无凭据：展示等待／不可用，保留原文及成功缓存。
- 演示子集与万条背景：分别标明来源、规模和证据，不混淆评价结论。

## Requirements

### Functional Requirements
- **FR-001**: 提供本机启动、状态查询、停止及可复现演示说明。
- **FR-002**: 完成目标、推荐、全文、显式已读、重新推荐的真实网页流程。
- **FR-003**: 推荐与资料保留来源、版本和计算证据；禁止固定文档答案冒充算法结果。
- **FR-004**: 翻译采用免费远程服务；缺凭据不影响原生中文全文阅读。
- **FR-005**: 六项交付物须完整列出；无法取得的真实信息明确缺口，不编造。
- **FR-006**: 视频为MP4且时长≤300秒，PPT可编辑，提示词为Markdown。
- **FR-007**: 如实说明单机部署、演示子集、质量未通过及未演示的流程。
- **FR-008**: 保存真实Git提交，不改写历史、不伪造开发时间；打包不得含密钥。

### Key Entities
- 演示运行：输入资料清单、账户、目标、处理结果和日志。
- 交付材料：六项路径、生成方式、真实依据、缺失信息与核验结果。
- 翻译版本：源文版本、服务与模型、配置、完整性状态和译文。

## Success Criteria

### Measurable Outcomes
- **SC-001**: 在同一实际网页会话完成登录、目标、推荐、中文阅读、标记已读和重算；逐步保存证据。
- **SC-002**: 六项交付均有可打开的产物或明确外部依赖说明；视频可解码且≤300秒。
- **SC-003**: 文档、视频和PPT不将演示跑通等同普遍推荐正确，不把历史未通过改成通过。
- **SC-004**: 免费远程模式在缺凭据或请求失败时不启动本地翻译；实际质量未测单独标记。

## Assumptions
[已确认] 当前只有一台电脑，规模扩展后置；此次优先可演示和课程交付。
[方案] 中文工程演示使用既有可追溯资料子集；完整万条处理展示历史真实证据。
[已验证] 旧报告有陶文杰、陈铭宇及50/50初版分工。最终贡献事实仅能由成员确认。
[范围] 011效果问题仍保留，012不替代011产品正确性验收；视频覆盖本次可运行功能，并交代RSS等未完成闭环。
